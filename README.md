# E-Commerce Sales & Profit Analysis

## Project Overview

This project analyzes 10,000 e-commerce sales records using Microsoft Excel to understand sales performance, profitability, product performance, regional trends, and the impact of discounts.

## Tools & Techniques

- Microsoft Excel
- Data Cleaning & Preparation
- Excel Formulas
- PivotTables
- PivotCharts
- Data Visualization
- Dashboard Creation
- KPI Analysis

## Key Analysis

The project analyzes:

- Total Sales
- Total Profit
- Profit Margin
- Sales by Category
- Sales and Profit by Region
- Product Performance
- Monthly Sales and Profit Trends
- Quantity Sold
- Impact of Discounts on Profitability

## Project Structure

- `Ecommerce_Sales_Profit_Analysis.xlsx` — Complete Excel analysis, PivotTables, dashboard, and visualizations.

## Skills Demonstrated

- Data analysis
- Data cleaning
- Excel formulas
- PivotTable and PivotChart creation
- Dashboard development
- Data visualization
- Business insights
